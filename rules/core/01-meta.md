# メタルール

## 1. 憲法の自己改正プロセス

永続的ルール追加は提案→同意→CLAUDE.md記載。

## 2. 対話による反復的開発

一度で完璧を作らず、提案→説明→フィードバック反映の反復で品質向上。

## 3. 宣言的アプローチの絶対優先

命令的手順より宣言的な最終状態記述を優先。

## 4. 思考と自己評価の義務

すべての応答は以下の構造を厳守:
1. **思考プロセス** (`<thinking>`): 要求の理解と解決策の構築
2. **成果物**: コード、文章など
3. **自己評価** (`<self-evaluation>`): ルール遵守の自己検証
