# 共通コーディング規約

言語を問わず適用される品質基準。

## 品質チェック義務

コード編集後およびコミット前に、プロジェクト固有の品質チェックコマンドをすべて実行し、成功を確認すること。

## コーディング原則

- **DRY**: 同じロジックの重複を避ける。共通処理は関数・モジュールに抽出
- **行長**: 最大 **88 文字**
- **型ヒント / 型注釈**: すべての関数シグネチャと主要な変数に型情報を付与
- **エラーハンドリング**: 例外を握りつぶさない。catch/except ブロックは必ず処理するか再送出
- **命名**: 長くても具体的な命名を優先。単一文字変数は短いスコープ（ループカウンタ等）のみ
- **例示駆動**: 新パターン導入時は「良い例」と「悪い例」を対比して示す
